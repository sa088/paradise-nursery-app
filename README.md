# Paradise Nursery 🌿

**Paradise Nursery** is a dynamic React + Redux shopping cart web application for an
online plant shop. Users can browse houseplants by category, view plant details
(image, name, description, and price), add items to a shopping cart, and manage
cart quantities in real time.

## Project Name
Paradise Nursery — Online Plant Shop Shopping Cart Application

## Features
- Landing page with company branding and a "Get Started" button
- Product listing page with plants grouped into categories
- Add-to-cart functionality with disabled state after adding
- Dynamic cart icon showing total item count
- Full shopping cart page with quantity controls, item removal, and total cost
- Checkout button ("Coming Soon") and Continue Shopping navigation

## Tech Stack
- React (Vite)
- Redux Toolkit
- React Router DOM
- CSS3

## Getting Started

```bash
npm install
npm run dev
```

Then open the local URL shown in your terminal (typically `http://localhost:5173`).
